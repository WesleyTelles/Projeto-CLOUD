Limitações Conhecidas e TroubleshootingValidação de Certificado SSL (DB_SSL=no-verify): Ao utilizar DB_SSL=true, o driver pg do Node.js rejeita a cadeia de certificado padrão do Azure Database for PostgreSQL. Conforme previsto no guia de implantação, optou-se por configurar DB_SSL=no-verify mantendo a criptografia TLS ativa (sslmode=require) na string de conexão.Fuso Horário: O servidor Linux do App Service opera em UTC (Z), enquanto a aplicação trata e exibe datas no fuso America/Recife.5.
